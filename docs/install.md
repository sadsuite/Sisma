# Requisiti
Un moderno browser web (Chrome, Firefox, Edge, Safari).
Connessione a internet (necessaria per le chiamate API e il caricamento di Bootstrap via CDN).
Nessun server backend o installazione di Node.js è richiesta.

# Clonazione Repository
Apri il terminale ed esegui:

```bash
git clone https://github.com/sadsuite/Sisma.git
cd Sisma/src
```
Oppure scarica e decomprimi l'archivio ZIP dal repository.

# Apertura del Sito
Poiché il progetto utilizza solo JavaScript lato client, è sufficiente aprire il file "index.html" direttamente nel browser.
